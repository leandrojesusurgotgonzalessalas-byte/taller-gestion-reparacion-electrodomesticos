# Registro de trabajo

14 de octubre de 2026 · America/La_Paz.

1. Se creó el repositorio Git local y la solución de Visual Studio con ASP.NET Core MVC, C#/.NET 9, Razor, Bootstrap local, EF Core SQL Server y YARP.
2. Se creó la base exclusiva TallerElectrodomesticos en localhost, usando la identidad Windows del equipo.
3. Se implementaron clientes, equipos, órdenes, piezas, diagnósticos, presupuestos, pagos, estados, auditoría y comprobantes.
4. A petición de Leandro se añadió el alcance del negocio pequeño: empleados, proveedores y arreglos a domicilio. Se incorporó dirección obligatoria para domicilio, empleado asignado y proveedor de piezas.
5. Se publicaron ejecutables con runtime .NET incluido, iniciador CMD de doble clic verificado con Windows PowerShell 5.1, control de procesos y script de respaldo verificado.
6. Se preparó el diseño nativo para Oracle SQL Developer Data Modeler a partir del DDL SQL Server, con nueve entidades, nueve tablas y ocho relaciones, más vistas distribuidas y diagramas de consulta.
7. Se ejecutaron pruebas funcionales contra SQL Server y un recorrido HTTP completo, incluyendo decimales, antifalsificación, stock, concurrencia, cobros, entrega, domicilio y comprobantes. Los resultados se conservaron en docs.

Los cambios de código y documentación se registran también en el historial Git. Runtime, registros locales y respaldos están excluidos de Git para no mezclar archivos de ejecución y datos con el código.

8. Nombre visible actualizado por indicación de Leandro: **TALLER DE GESTION DE REPARACION DE ELECTRODOMESTICOS**. Se actualizaron interfaz, comprobantes, documentación e iniciador del escritorio.
